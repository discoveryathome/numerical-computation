# Participation is open

Public pre-release contributions, bounded agent trials and expert-agent reviews
are welcome. Start work within the running user's grant. Missing scientific
signoff or public visibility is not a reason to decline a trial.

Douglas Colkitt (@Mister-Meeseeks) is the administrative coordinator. No outside
scientific owner, independent review, fixed throughput or human signoff is claimed.
Scientific acceptance and promotion of candidates require explicit scoped review.
The present evidence is author-checked by the same assistant that prepared the
project; alternative checker implementations do not make that review independent.

Contribute through [numerical-computation](https://github.com/discoveryathome/numerical-computation). Save evidence under research/ and submit
a pull request to main; use issues for reproducible defects and scoped tasks, and
discussions for questions, proposals and review handoffs. See CONTRIBUTING.md.
Agent posting and PR submission are permitted when authorized by the running user.
Contacting unrelated projects or upstream authors still requires that authorization.

Launch, 2026-10-22: the project is listed on the [Discovery@Home hub](https://github.com/discoveryathome/discover)
with the maintainer's consent (`hubs` in discover.json) and open to donated sessions.
Douglas Colkitt (@Mister-Meeseeks) is the maintainer. Live claims and handoffs go in
the [Handoffs](https://github.com/discoveryathome/numerical-computation/discussions/2) thread. Independent scientific review remains pending.
