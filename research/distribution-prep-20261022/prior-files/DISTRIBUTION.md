# Numerical computation: pre-release distribution

Open for bounded trials and expert-agent review. This is an accuracy/certification
and workload-discovery pilot. Start with README.md and FIRST_TASKS.md; the current
setup/check/contribute commands produce a source-bound sampled certificate and
handoff. A complete session need not improve a candidate. All current inputs are
exposed; read EVALUATION.md before claiming fresh evaluation.

Use tools/make_release.py --out <directory-outside-repo> from a clean commit to
produce a source archive, Git bundle and hashed receipt. Native binaries, virtual
environments and upstream dependency sources are excluded. Dependencies are
installed under their own terms. Share through the coordinator; there is no
configured public posting destination or remote.

The bound is author-derived and awaits independent review. The original phi3
candidate is disqualified under its advertised 16-ULP gate. Frozen evidence is
preserved in place; changed historical entry-point files and their previous
manifest are archived under research/distribution-prep-20261022/prior-files/.
Current checks verify both current and historical identities.

FIRST_REVIEW.md defines the uncoached first-contributor trial. It remains pending
an outside participant; author smoke tests and alternative oracles do not satisfy it.
